# ServiceNow ITSM Incident Debugger

A rule-based troubleshooting assistant for ServiceNow ITSM incidents.

## Features

- Analyze ServiceNow incidents
- Identify issue category
- Suggest possible root causes
- Provide troubleshooting steps
- Recommend next actions
- Support common ITSM issues like VPN, LDAP, Email and Login problems
